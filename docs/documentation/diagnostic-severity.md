
## 🎯 Severity Levels

| Level                  | Meaning                                                | Recommendation for the user            |
| :--------------------- | :------------------------------------------------------ | :------------------------------------- |
| ❌ **Error**            | A critical issue affecting the correctness of the project. | Must be fixed.                      |
| ⚠️ **Warning**         | A potential issue that requires attention.               | Recommended to fix or review.          |
| 💬 **Message**         | An informational message with no strict requirements.    | Review at your discretion.             |
