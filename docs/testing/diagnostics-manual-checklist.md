# Ручная проверка диагностик

Прогонять в debug-сборке на каждой доступной версии Revit. Использовать одноразовые модели, фиксы на боевых документах не проверять.

Легенда визуализации: **Показать+Выбрать** — находка с геометрией, presenter создаёт/активирует вид `Revit Linter — Visualization`; **Только выбрать** — у цели нет геометрии модели, вид не трогается; **Открыть вид** — цель сама является видом или листом, presenter открывает её и не создаёт 3D-вид визуализации. Легенда области: 🏢 проект, 🏠 семейство.

- [ ] Сборка и модель зафиксированы (версия Revit, версия аддина, пути к тестовым `.rvt`/`.rfa` записаны)
- [ ] Пустой прогон: все проверки включены, находок нет — отчёт пуст, ошибок в логе нет
