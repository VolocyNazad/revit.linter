Install project-parameter checks and per-parameter element fill checks generated from the ADSK Revit 2021 project templates from the welcome window on every supported Revit version: the Examples step appends the checks of the selected disciplines to the installed example configuration in the parameter group spelling of the running version, `PG_*` names on Revit 2021-2023 and ForgeTypeId values on Revit 2024-2027, and the fill checks report a Message finding for an empty text parameter, which disappears after the parameter is filled.
