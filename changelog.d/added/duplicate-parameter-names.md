New built-in checks `DOC004` and `SHRD0044` report one name shared by two parameters. `DOC004` finds project parameters whose definitions differ but whose names match, which happens with two parameter files and with a project parameter added next to a family one, and names each definition with its GUID and categories. `SHRD0044` finds a family instance that carries both a family parameter and a project parameter with one name, names the element and counts the bound parameters. A custom parameter that only repeats a built-in parameter name is not reported.
