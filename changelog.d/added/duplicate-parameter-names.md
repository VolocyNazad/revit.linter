New built-in checks `DOC004` and `SHRD0044` report one name shared by two parameters. `DOC004` finds project parameters whose definitions differ but whose names match, which happens with two parameter files, and names each definition with its GUID and categories. `SHRD0044` finds a family that adds its own parameter with the same name as a project parameter bound to its category, names the family and counts the bound parameters, once per family rather than once per type or instance. A parameter that is the same shared definition in the family and the project is not a duplicate, and a custom parameter that only repeats a built-in parameter name is not reported.
