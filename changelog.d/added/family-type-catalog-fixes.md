`SHRD0046`, `SHRD0047` and `SHRD0049` gain fixes: create the type catalog from the family types and remove them from the family, add the missing types to the catalog and remove them, or add the missing parameters. The catalog and values use the Autodesk type catalog format: measurable specs and units from `UnitUtils.GetTypeCatalogStringForSpec/Unit`, `OTHER` for the rest, `1` and `0` for yes/no, `Family : Type` for a family type and the material name for a material. Both fixes that remove types ask for confirmation first: the create fix keeps only the active type, and the append fix keeps the last type. The family change is undone with the transaction; the catalog file is not.
