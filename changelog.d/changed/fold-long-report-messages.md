A long list of element names or identifiers in a report message is folded into its first items and a `+N` counter, and clicking the counter opens the complete list in a popup, one element per line. Every name in the folded line is quoted, so a name that itself contains a comma stays readable. Only list values are folded: long scalar text such as a Revit warning description is not shortened. The search, the sort and the export still use the complete message.
