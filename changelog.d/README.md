# Changelog fragments

A change carries its entry as one file under a category directory here:
`added/`, `changed/`, `deprecated/`, `removed/`, `fixed/` or `security/`.

Name the file with a lowercase kebab-case slug that describes the change, such as
`keep-selected-row-after-refresh.md`, and write one line of entry text without the `- ` marker.
Do not edit `CHANGELOG.md` directly: the entries are collected and finalized when a release is
prepared.

The rules and the commands are in the [changelog policy](../docs/policies/changelog.md).
