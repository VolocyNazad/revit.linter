> Language: **English** · [[Панель результатов исправлений|Русский]]

Panel with the results of the fixes applied in the current session. Ignoring a finding and removing an ignore entry are reported here as well.

The search box shows only the fixes whose code or message holds the text. The list is updated when you leave the field. The search switches follow the shared table controls in [[Dockable panes#Shared table controls]].

A long list of element names or identifiers is folded the same way as in the diagnostic report: every name is quoted in the folded line, and the `+N` counter opens the complete list in a popup, one element per line.

The **Columns** button chooses which data columns the table shows; see [[Dockable panes#Shared table controls]].

Hover over a toolbar button to see what it does; the question-mark button of the tool bar opens this page. While the tooltip is shown, press **F1** to open this page in the default browser.
