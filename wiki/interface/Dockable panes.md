In Revit, **"Dockable panes"** are interface elements that can be freely moved, docked to the edges of the main program window, or floated (including on additional monitors). This allows you to flexibly customize your workspace to your preferences.

## Shared table controls

All four tables use the same controls.

- The **Columns** button chooses which data columns the table shows. The row action buttons always stay visible, at least one data column stays visible, and hiding a column keeps the current sort order. The choice and the column widths are remembered per user across Revit versions.
- The **Code** column sorts by the text of the code and by its numbers, so `CSTM2` comes before `CSTM10`.
- The search box has **Aa** for case matching and **ab|** for whole words. Both are off by default. Try `Wall` with **Aa** pressed, or `wall` with **ab|** pressed: the first finds only `Wall`, the second does not find `wallboard`.
- The search text, the search switches, the filter choice and the sort order are remembered per table and restored when Revit starts.
