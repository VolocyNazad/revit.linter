# Sponsor button

The **Sponsor** button opens the author's [GitHub Sponsors page](https://github.com/sponsors/VolocyNazad) in the default browser.

> [!note]
> Sponsorship is optional and does not unlock features or change Revit Linter behavior. If Windows cannot start the default browser, Revit Linter records the failure in its log and displays an error message.
