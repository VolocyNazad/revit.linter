# Support button

The **Support** button opens the [Revit Linter issue tracker](https://github.com/VolocyNazad/revit.linter/issues) in the default browser. Use it to report a problem, suggest an improvement, or ask for help.

> [!note]
> Opening the page does not depend on the active Revit document and does not modify the model. If Windows cannot start the default browser, Revit Linter records the failure in its log and displays an error message.
