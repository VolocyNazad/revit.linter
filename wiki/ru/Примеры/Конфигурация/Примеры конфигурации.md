Файлы рядом с этой страницей — готовые шаблоны конфигурации, которые хранятся вместе с документацией. Revit Linter не считывает их непосредственно из репозитория.

Шаблоны предоставляются для трех настраиваемых модулей:

- [`config.yaml`](../../../examples/configuration/config.yaml) — [[Пользовательские проверки]];
- [`collision.config.yaml`](../../../examples/configuration/collision.config.yaml) — [[Проверки коллизий]];
- [`parameter-element.config.yaml`](../../../examples/configuration/parameter-element.config.yaml) — [[Проверки параметров проекта]].

## Рабочая конфигурация

Revit Linter считывает рабочие файлы YAML, которые пользователь создает или редактирует в [[Размещение файлов конфигурации]] для текущей версии Revit. Например, Revit 2025 использует:

`C:\Users\{UserName}\Documents\Revit Linter\2025\`

Самый простой способ открыть эту папку — [[Кнопка папки конфигурации]] на вкладке ленты **Volocy**.

Чтобы использовать шаблон, скопируйте его в рабочую папку конфигурации под указанным именем. Затем замените условия, GUID, имена параметров и категории значениями из своего проекта. Проверки с `isActive: false` по умолчанию не запускаются.
