Файлы рядом с английской версией этой страницы — рабочие примеры конфигурации, которые хранятся вместе с документацией. Revit Linter не считывает их из репозитория: эти же файлы устанавливает [[Кнопка начала работы|окно знакомства]], либо их можно скопировать вручную.

| Файл | Модуль | Содержимое |
| --- | --- | --- |
| [`config.yaml`](../../../examples/configuration/ru/config.yaml) | [[Пользовательские проверки]] | Шесть проверок: экземпляры обобщённых моделей, воздуховоды и трубы без системы, двери и окна без марки, зеркальные двери, помещения без осмысленного имени и неразмещённые помещения с исправлением **Удалить**. |
| [`collision.config.yaml`](../../../examples/configuration/ru/collision.config.yaml) | [[Проверки коллизий]] | Девять правил, по три на раздел: инженерные системы (`CLSN1xx`), архитектура (`CLSN2xx`) и конструкции (`CLSN3xx`). |
| [`parameter-element.config.yaml`](../../../examples/configuration/ru/parameter-element.config.yaml) | [[Проверки параметров проекта]] | По одному правилу на раздел на основе файла общих параметров ADSK: `PRMTR101`, `PRMTR201` и `PRMTR301`. |

Ссылки ведут на файлы с русскими текстами сообщений; те же файлы с английскими текстами лежат [уровнем выше](../../../examples/configuration/config.yaml). В формулах параметры заданы именами `BuiltInParameter`, поэтому правила работают в Revit на любом языке.

## Блоки разделов

В файлах коллизий и параметров проекта каждый раздел заключён в пару строк-комментариев:

```yaml
# >>> section: mep — Инженерные системы (ИОС)
- code: "CLSN101"
  ...
# <<< section: mep
```

Окно знакомства оставляет только блоки выбранных разделов (`mep`, `architecture`, `structure`). При ручном копировании удалите ненужные блоки или оставьте все.

## Что важно учитывать

- Коллизии ищутся внутри одного документа; связанные модели не участвуют. Правило отбирает элементы по категории и классу, поэтому несущую стену от архитектурной оно не отличит. Запускайте блок в модели своего раздела или сузьте его через `takeDocument`.
- В примерах `groupBy` — константа, поэтому каждый отобранный элемент сравнивается с каждым. Замените её формулой, чтобы сравнивать элементы только внутри группы.
- Правила параметров проекта используют имена и GUID из файла общих параметров ADSK. Тип привязки, категории и группа — пример стандарта компании; приведите их к своему шаблону.
- Файл параметров проекта использует формат `group` для Revit 2024 и новее. Для Revit 2021–2023 замените его именем `BuiltInParameterGroup`, например `PG_DATA`: правило, у которого `group` не подходит запущенной версии Revit, пропускается при загрузке файла. Окно знакомства заменяет группу автоматически. Подробнее — [[Проверки параметров проекта]].

## Рабочая конфигурация

Revit Linter считывает рабочие файлы YAML из [[Размещение файлов конфигурации|папки конфигурации]] для текущей версии Revit. Например, Revit 2025 использует:

`C:\Users\{UserName}\Documents\Revit Linter\2025\`

Самый простой способ открыть эту папку — [[Кнопка папки конфигурации]] на вкладке ленты **Диагностика**. Чтобы использовать пример вручную, скопируйте его в эту папку под указанным именем.
