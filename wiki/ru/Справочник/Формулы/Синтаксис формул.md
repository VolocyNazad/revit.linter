## Значения

| Тип | Синтаксис | Примеры |
| --- | --- | --- |
| Номер (`double`) | целочисленное или десятичное обозначение с точкой | `0`, `-3`, `12.5` |
| Строка (`string`) | одинарные кавычки | `'Wall 01'`, `''` |
| Логическое значение (`bool`) | `true` или `false` | `true` |
| Пустое значение | `null` | `null` |
| Число π | `pi` | `2 * pi` |

### Экранирование строки

Поддерживаются `\'`, `\\`, `\n`, `\r`, `\t`, `\f` и `\b`. Неизвестная escape-последовательность сохраняется без изменений.

```text
'it\'s'       // it's
'a\\b'        // a\b
'line1\nline2'
```

## Операторы

Операторы перечислены от высшего приоритета к низшему.

| Приоритет | Операторы | Назначение |
| ---: | --- | --- |
| 1 | `^` | Возведение в степень |
| 2 | `*`, `/`, `%` | Умножение, деление, остаток |
| 3 | `+`, `-` | Сложение/конкатенация, вычитание |
| 4 | `!` | Логическое НЕ |
| 5 | `>`, `>=`, `<`, `<=` | Числовое сравнение |
| 6 | `==`, `!=` | Равенство и неравенство |
| 7 | `&` | Логическое И |
| 8 | `\|` | Логическое ИЛИ |

```text
2 + 3 * 4              // 14
(2 + 3) * 4            // 20
true | false & false   // true
!(1 > 2)               // true
```

`+` добавляет числа и объединяет строки. Если хотя бы один операнд является строкой, другой преобразуется в строку. При добавлении строки в `null` пустое значение становится пустой строкой; `null + null` возвращает `null`.

Числа в `==` и `!=` сравниваются с допуском около `1e-9`. Операторы `&` и `|` оценивают оба операнда.

> [!note]
> Деление соответствует поведению `double`: например, `1 / 0` возвращает положительную бесконечность.
