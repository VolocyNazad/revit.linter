# Пайплайны визуализации

Проверка элементов может объявлять несколько именованных пайплайнов. Если вариант один, отчёт запускает его сразу; если несколько — предлагает выбор. Шаги выполняются сверху вниз, а при завершении показа откатываются в обратном порядке.

```yaml
visualizations:
  - name: "Показать"
    steps:
      - type: "Show"
        elementSets: ["Target"]
```

`name` обязателен и не может быть пустым. `steps` — обязательная непустая последовательность. Если `visualizations` отсутствует, создаётся стандартный пайплайн `Show`.

## Наборы элементов

`elementSets` выбирает именованные группы, переданные диагностикой. Отсутствующий или пустой список объединяет все доступные группы. Неизвестное имя прерывает пайплайн с ошибкой конфигурации.

| Ключ | Значение |
| --- | --- |
| `Target` | Элементы, непосредственно сформировавшие результат проверки. |
| `Dependencies` | Связанные элементы, объясняющие результат, включая вторую сторону коллизии. |

## Шаги

| `type` | Обязательные поля | Действие и откат |
| --- | --- | --- |
| `Show` | нет | Приближает элементы; возвращает прежнюю область просмотра. |
| `Select` | нет | Выбирает элементы; возвращает прежнее выделение. |
| `Isolate` | нет | Временно изолирует элементы; отключает изоляцию при откате. Уже активную до запуска изоляцию не заменяет. |
| `Cut` | нет | Настраивает секущий параллелепипед 3D-вида; возвращает прежний параллелепипед и его активность. |
| `OverrideElements` | `style` | Переопределяет графику отдельных элементов и возвращает прежние настройки каждого элемента. |
| `OverrideFilter` | `style` | Создаёт временный `SelectionFilterElement` и при откате удаляет только созданный фильтр. |

Поле `style` недопустимо для `Show`, `Select`, `Isolate` и `Cut` и обязательно для обоих видов переопределения графики.

## Стиль графики

Все свойства необязательны. Пропущенное свойство сохраняет соответствующую настройку Revit.

| Свойство | Тип и диапазон |
| --- | --- |
| `halftone` | `true` или `false` |
| `transparency` | целое число от `0` до `100` |
| `detailLevel` | `Coarse`, `Medium` или `Fine` |
| `projectionLines`, `cutLines` | стиль линий |
| `surfaceForeground`, `surfaceBackground`, `cutForeground`, `cutBackground` | стиль штриховки |

Стиль линий поддерживает `color` в формате `#RRGGBB`, `pattern` с именем образца линий Revit (`Solid` означает сплошную линию) и `weight` от `1` до `16`.

Стиль штриховки поддерживает `color` в формате `#RRGGBB`, `pattern` с именем образца заливки Revit (`SolidFill` выбирает сплошную заливку документа) и `isVisible`. Имена сравниваются без учёта регистра в текущем документе. Если образец не найден, показ прерывается, а выполненные шаги откатываются.

```yaml
style:
  halftone: false
  transparency: 25
  detailLevel: "Fine"
  projectionLines: { color: "#E53935", pattern: "Solid", weight: 6 }
  cutLines: { color: "#B71C1C", weight: 8 }
  surfaceForeground: { color: "#E53935", pattern: "SolidFill", isVisible: true }
  surfaceBackground: { color: "#FFCDD2", pattern: "SolidFill", isVisible: true }
  cutForeground: { color: "#B71C1C", pattern: "SolidFill", isVisible: true }
  cutBackground: { color: "#FF8A80", pattern: "SolidFill", isVisible: true }
```

## Полный пример для коллизии

```yaml
visualizations:
  - name: "Коллизия: красный и зелёный"
    steps:
      - type: "OverrideElements"
        elementSets: ["Target"]
        style:
          transparency: 15
          projectionLines: { color: "#E53935", weight: 6 }
          surfaceForeground: { color: "#E53935", pattern: "SolidFill", isVisible: true }
      - type: "OverrideElements"
        elementSets: ["Dependencies"]
        style:
          transparency: 35
          projectionLines: { color: "#43A047", weight: 6 }
          surfaceForeground: { color: "#43A047", pattern: "SolidFill", isVisible: true }
      - type: "Show"
        elementSets: ["Target", "Dependencies"]
      - type: "Cut"
        elementSets: ["Target", "Dependencies"]

  - name: "Коллизия через фильтры"
    steps:
      - type: "OverrideFilter"
        elementSets: ["Target"]
        style:
          halftone: false
          surfaceForeground: { color: "#E53935", pattern: "SolidFill", isVisible: true }
      - type: "OverrideFilter"
        elementSets: ["Dependencies"]
        style:
          halftone: true
          surfaceForeground: { color: "#43A047", pattern: "SolidFill", isVisible: true }
      - type: "Isolate"
        elementSets: ["Target", "Dependencies"]
      - type: "Select"
        elementSets: ["Target"]
```

Одновременно активен только один пайплайн. Перед запуском другого активный пайплайн откатывается. Очистка или закрытие отчёта и смена контекста Revit также восстанавливают исходное состояние.
