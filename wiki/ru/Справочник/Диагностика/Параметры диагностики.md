> Язык: [[Diagnostic parameters|English]] · **Русский**

| Свойство                | Тип                                           | Описание                                                                                                                                    | Пример                                                                                                                                               |
| :----------------------- | :--------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`Code`**                | `string`                                      | Уникальный идентификатор проверки в формате `[Префикс][Номер]`. Префикс определяет категорию проверки.                                 | `SHRD001`                                                                                                                                            |
| **`Description`**         | `string`                                      | Краткое описание назначения проверки.                                                                                           | `Проверяет, используются ли семейства в документе.`                                                                                                 |
| **`MessageFormat`** | `string` | Шаблон сообщения, отображаемый пользователю. Поддерживает подстановки значений в фигурных скобках. | `Element with name '{elementName}' and identifier '{elementId}' ...` |
| **`DefaultSeverity`** | [[Уровни важности\|`DiagnosticSeverity`]] | Уровень важности по умолчанию. Пользователь может изменить его в настройках.                                                                | `DiagnosticSeverity.Warning`                                                                                                                         |
| **`IsActive`**            | `bool`                                        | Включена ли проверка по умолчанию. Если указано `false`, проверка не запускается, пока пользователь явно её не включит.                           | `true`                                                                                                                                               |
| **`IsObsolete`**          | `bool`                                        | Помечена ли проверка как устаревшая. Устаревшие проверки могут быть удалены в будущих версиях.                                           | `false`                                                                                                                                              |
| **`ObsoleteDescription`** | `string`                                      | Причина устаревания и, при наличии, код заменяющей проверки. Остаётся пустым, пока проверка актуальна.                      | `Используйте SHRD003 вместо этой проверки.`                                                                                                          |
