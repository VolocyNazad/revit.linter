## Windows

1. Закройте Revit.
2. Откройте страницу [Revit Linter releases](https://github.com/VolocyNazad/revit.linter/releases).
3. Загрузите MSI-установщик Revit Linter.
4. Запустите установщик, проверьте найденные версии Revit и при необходимости измените выбранные компоненты.
5. Запустите Revit и найдите команды на вкладке ленты **Диагностика**.

Единый пользовательский установщик содержит сборки для Revit 2021, 2023 и 2025, а также общий
updater. Повышение прав не требуется. Файлы приложения устанавливаются в локальные данные текущего
пользователя, а манифесты Revit регистрируются отдельно для каждого поддерживаемого года.

Установщик заменяет файлы дополнения только при закрытом Revit. Если обнаружен запущенный процесс
Revit, установка прекращается без изменения файлов и предлагает закрыть Revit, а затем запустить ее
снова. При обновлении Windows Installer по возможности сохраняет прежний выбор компонентов.

После действия **Скачать** в уведомлении updater сохраняет MSI в
`%LOCALAPPDATA%\Volocy\Revit.Linter\updater\downloads\` только при совпадении размера и SHA-256 из
метаданных релиза GitHub. Проводник открывается с выбранным файлом, но установка автоматически не
запускается. Закройте Revit и явно запустите проверенный MSI.

## Политики обновления для администраторов

Revit Linter читает необязательные политики из `Software\Policies\Volocy\Revit.Linter\Updater` в
`HKEY_LOCAL_MACHINE` и `HKEY_CURRENT_USER`. Наивысший приоритет имеет политика компьютера,
далее идут политика пользователя, пользовательские настройки и встроенные значения. Установщик не
создает эти параметры.

| Параметр | Тип реестра | Назначение |
|---|---|---|
| `ChecksEnabled` | `DWORD` (`0` или `1`) | Запрещает или разрешает все автоматические и ручные проверки. |
| `NotificationsEnabled` | `DWORD` (`0` или `1`) | Запрещает или разрешает уведомления Windows, не отключая проверки. |
| `CheckIntervalHours` | `DWORD` (`1`–`720`) | Задает интервал успешных автоматических проверок; по умолчанию 24 часа. |
| `ReleaseApiUrl` | `REG_SZ` | Заменяет endpoint API последнего релиза; принимается только абсолютный HTTPS URL. |

Некорректные значения игнорируются и записываются в лог. Revit Linter только читает политики и не
сохраняет их в пользовательское состояние updater.

## Устранение неполадок

- Если вкладка **Диагностика** отсутствует, закройте все процессы Revit и снова запустите программу установки.
- Убедитесь, что открытая версия Revit входит в приведенный выше список поддерживаемых версий.
- Если панель скрыта, используйте [[Кнопки ленты]], чтобы показать ее снова.
