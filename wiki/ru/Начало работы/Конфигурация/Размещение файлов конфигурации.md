> Язык: [[Diagnostic configuration path convention|English]] · **Русский**

Конфигурации хранятся отдельно для каждой версии Revit:

Пути для поддерживаемых версий Revit приведены на странице [[Путь к конфигурации]].

Пример для Revit 2021:

`C:\Users\Owner\Documents\Revit Linter\2021\`

Используйте [[Кнопка папки конфигурации]], чтобы открыть нужную папку непосредственно из Revit.
