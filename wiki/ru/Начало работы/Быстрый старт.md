# Быстрый старт

Обычный сценарий работы:

`Модель → Проверки → Список проблем → Показать или исправить → Экспорт отчёта`

## Документ уже открыт

1. На вкладке ленты **Диагностика** откройте [[Панель диагностики]] и [[Панель результатов диагностики]].
2. На панели **Диагностика** выберите подходящие проверки. Начните со [[Встроенные проверки и пользовательские правила|встроенных проверок]] — им не нужна настройка.
3. На панели **Результаты диагностики** выберите активный документ и нажмите **Выполнить**.
4. Выберите замечание, прочитайте сообщение и используйте **Показать**, чтобы найти элемент.
5. Применяйте предложенное исправление только после проверки подтверждения. При необходимости экспортируйте отображаемые замечания в отчёт.

## Документ не открыт

Откройте [[Кнопка начала работы|Начало работы]] и выберите один из вариантов:

- подготовить новую копию официального примера Autodesk, найденного для запущенной версии Revit;
- начать практическое обучение и открыть свой проект или семейство, когда будете готовы.

Практическое обучение дождётся документа и продолжится автоматически. Сохранение прогресса, отказ и сброс описаны на странице [[Практическое обучение]].

Revit обычно закрепляет панели в нижней части окна. Их можно перемещать, изменять их размер и откреплять, как и другие [[Закрепляемые панели]].

> **Примечание:** **Показать** приближает замечание или применяет другую визуализацию в активном виде Revit. Повторный щелчок по той же активной визуализации восстанавливает прежнее состояние вида.
