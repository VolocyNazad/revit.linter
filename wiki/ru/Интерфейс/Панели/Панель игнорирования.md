# Панель игнорирования

Панель **Игнорирования** показывает, какие проверки отключены в активном документе, и позволяет снять игнорирование. Revit открывает её вкладкой рядом с панелями результатов. Список хранится внутри самой модели, поэтому переносится вместе с файлом и не требует настройки.

Панель следует за активным документом: при переключении документа показывается список другого документа.

## Столбцы

| Столбец | Значение |
| --- | --- |
| **Код** | Код проверки, к которой относится запись. |
| **Область** | **Элемент** — отключён только этот элемент; **Документ** — проверка отключена во всём документе. |
| **Id** | Идентификатор элемента Revit; пусто для записи обо всём документе. |
| **Объект** | Имя элемента, название документа или **Удаленный элемент**, если сохранённого элемента больше нет. |

## Действия

- **Показать** (глаз в строке) выбирает объект записи в модели. Недоступно для записи обо всём документе, для удалённого элемента и в семействах.
- **Убрать** (корзина в строке) снимает игнорирование записи. При следующем запуске проверка снова покажет замечание.
- **Очистить всё** (на панели) убирает все записи активного документа после подтверждения.
- **Обновить** (на панели) перечитывает список.
- На панели также расположены общие кнопки проверок (запуск, пауза, «на активном виде») и показано название активного документа.
- Поиск фильтрует список по коду и объекту без учёта регистра. Список обновляется, когда вы покидаете поле.

Записи, элементы которых больше не существуют, удаляются при следующей загрузке панели, обновлении списка и при каждой записи в список. Запись обо всём документе остаётся, пока её не уберут вручную.

> **Примечание:** игнорирование, сохранённое Revit Linter 2.0.0 в параметрах проекта `Linter_Ignored` и `Linter_IgnoredType`, текущая версия не читает. См. [[Устранение неполадок]].

Наведите указатель на кнопку панели, чтобы увидеть её описание; кнопка со знаком вопроса открывает эту страницу. Пока подсказка показана, нажмите **F1**, чтобы открыть эту страницу в браузере.
