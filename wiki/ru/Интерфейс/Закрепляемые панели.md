## Общие элементы таблиц

Во всех четырёх таблицах одинаковые элементы управления.

- Кнопка **Столбцы** выбирает столбцы с данными. Кнопки действий в строках остаются видимыми, хотя бы один столбец с данными остаётся видимым, а скрытие столбца не меняет текущую сортировку. Выбор и ширина столбцов запоминаются для пользователя для всех версий Revit.
- Столбец **Код** сортирует по тексту кода и по его числам, поэтому `CSTM2` идёт перед `CSTM10`.
- В строке поиска есть **Aa** для учёта регистра и **ab|** для поиска слова целиком. По умолчанию обе выключены. Попробуйте `Wall` с нажатой **Aa** или `wall` с нажатой **ab|**: первая кнопка найдёт только `Wall`, вторая не найдёт `wallboard`.
- Текст поиска, кнопки поиска, выбранные фильтры и порядок сортировки запоминаются для каждой таблицы и восстанавливаются при запуске Revit.
