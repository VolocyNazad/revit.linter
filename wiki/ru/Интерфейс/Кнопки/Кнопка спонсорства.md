# Кнопка спонсорства

Кнопка **Спонсорство** открывает [страницу автора на GitHub Sponsors](https://github.com/sponsors/VolocyNazad) в браузере по умолчанию.

> [!note]
> Спонсорство добровольно, не открывает дополнительные функции и не меняет поведение Revit Linter. Если Windows не сможет запустить браузер по умолчанию, Revit Linter запишет ошибку в лог и покажет сообщение.
