# Кнопка начала работы

Кнопка **Начало работы** открывает окно знакомства. Это же окно появляется само при первом запуске Revit после установки Revit Linter.

В окне пять шагов:

1. **Добро пожаловать** — что делает плагин, последовательность **Модель Revit → Проверки → Замечания → Показать или исправить → Экспорт отчёта** и как называется его вкладка на ленте.
2. **Проверки** — сравнение встроенных проверок и пользовательских YAML-правил с представлением основных полей правила только для чтения.
3. **Примеры** — выберите разделы, с которыми работаете (инженерные системы, архитектура, конструкции), при необходимости отметьте **проверки по шаблонам ADSK** своих разделов и нажмите **Загрузить примеры**. [[Примеры конфигурации]] записываются в [[Размещение файлов конфигурации|папку конфигурации]] запущенной версии Revit.
4. **Практическое обучение** — запускает или продолжает [[Практическое обучение]]. Если документ не открыт, здесь можно подготовить одноразовую копию официального примера Autodesk, найденного для запущенной версии Revit, или выбрать работу со своим документом.
5. **Готово** — краткий итог и ссылки на быстрый старт, документацию и поддержку.

> [!note]
> Загрузка примеров всегда записывает в подпапку `examples` папки конфигурации; ваши файлы не затрагиваются. Скопируйте оттуда нужные правила в свои файлы конфигурации.

Блоки проверок по шаблонам ADSK предлагаются на каждой поддерживаемой версии Revit. Окно знакомства дописывает выпуск, соответствующий запущенной версии Revit: Revit 2021–2023 получает блоки, сгенерированные из шаблонов Revit 2021, с именами групп параметров `PG_*`, а Revit 2024–2027 — те же блоки со значениями групп ForgeTypeId, например `autodesk.parameter.group:data-1.0.0`. В обоих выпусках одни и те же проверки и коды. Каждый блок содержит правило параметров проекта своего раздела, которое требует, чтобы параметры шаблона сохраняли тип привязки, группу, список категорий и признак изменения по группам, и по одной проверке заполнения для каждого параметра типа «Текст» или «Многострочный текст», привязанного к категориям элементов; такая проверка сообщает об элементе с пустым параметром. Окно знакомства дописывает в установленный файл примеров и правило параметров проекта, и проверки заполнения выбранных разделов. Правило выполняется в любом документе-проекте, поэтому устанавливайте только свои разделы: в модели, созданной по шаблону другого раздела, таких параметров нет. Список кодов — в [[Примеры конфигурации]].

Автоматически окно показывается один раз для пользователя. Шаг **Примеры** предлагается один раз для каждой версии Revit, потому что у каждой версии своя папка конфигурации. Закрытие окна любым способом считается показом; кнопка всегда открывает полное знакомство.

Прогресс практического обучения также хранится отдельно для каждой версии Revit. Кнопка **Сбросить практическое обучение** очищает только этот прогресс: установленные примеры и состояние показа окна не меняются.
