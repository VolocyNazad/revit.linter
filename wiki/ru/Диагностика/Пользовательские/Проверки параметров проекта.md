> Язык: [[Project parameter diagnostics|English]] · **Русский**

Список проверок и их поведение задаются в YAML-файле. Он должен находиться в [[Размещение файлов конфигурации|папке конфигурации]] соответствующей версии Revit. Файл должен называться `parameter-element.config.yaml`.

Готовый файл: [parameter-element.config.yaml](../../../examples/configuration/parameter-element.config.yaml).

---

**Пример конфигурации:**`
```yml
- code: "PRMTR001"
  description: "custom"
  message: "Document named '{documentTitle}' contains invalid project parameters. Details: \n\n{details} \n\nExecution time '{duration}' ms."
  severity: "Message"
  isActive: false
  take: "!property('IsFamilyDocument')"
  parameters:
    - guid: "dd002437-b54b-41b5-9142-71704a513ef3"
      name: "CUBE_ID"
      group: "PG_TEXT"
      isInstance: true
      categories: ["OST_DuctCurves"]
      allowVaryBetweenGroups: true
    - guid: "2f60ce79-f71b-4b1e-9b74-7ce425cf3cec"
      name: "CUBE_Зависимости"
      group: "PG_TEXT"
      isInstance: true
      categories: ["-2008000"]
      allowVaryBetweenGroups: true
    - name: "Какой-то параметр"
      group: "PG_TEXT"
      isInstance: true
      categories: ["-2008000"]
      allowVaryBetweenGroups: true
- code: "PRMTR002"
  ...
```

---

**Параметры:**

| Поле                  | Тип              | Тип входных данных | Тип возвращаемого значения формулы | Назначение                                                                                                            |
| --------------------- | ---------------- | ------------------- | -------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `code`                | строка           | `string`            | `-`                              | Уникальный идентификатор проверки                                                                                     |
| `description`         | строка           | `string`            | `-`                              | Описание проверки                                                                                                     |
| `message`             | строка           | `string`            | `-`                              | Шаблон сообщения об ошибке. Доступные переменные: `{documentTitle}`, `{details}`, `{duration}`.                        |
| `severity`            | перечисление     | `string`            | `-`                              | [[Уровни важности]] <br>(по умолчанию: `Message`) (необязательно)                           |
| `isObsolete`          | логический | `bool`              | `-`                              | [[Устаревшие проверки]] (по умолчанию: `false`) (необязательно)                                |
| `obsoleteDescription` | строка           | `string`            | `-`                              | [[Устаревшие проверки]] (отображается, когда `isObsolete: true`) (необязательно) |
| `isActive`            | логический | `bool`              | `-`                              | Активна ли проверка (по умолчанию: `true`) (необязательно)                                                           |
| `take`                | строка           | `string`            | `bool`                           | Формула [[Синтаксис формул|фильтрации документов]]                                                              |
| `parameters`          | список           | `array`             | `-`                              | Список параметров проекта для проверки                                                                                |

---

**Параметры (поля внутри `parameters`):**

|Поле|Тип|Тип входных данных|Тип возвращаемого значения формулы|Назначение|
|---|---|---|---|---|
|`guid`|строка|`string`|`-`|GUID параметра|
|`name`|строка|`string`|`-`|Имя параметра|
|`group`|перечисление|`string`|`-`|Ожидаемая группа параметра|
|`isInstance`|логический|`bool`|`-`|Определяет вид параметра: параметр экземпляра (`true`) или параметр типа (`false`)|
|`categories`|список|`array`|`-`|Список категорий параметра, заданных идентификаторами или именами `BuiltInCategory`.|
|`allowVaryBetweenGroups`|логический|`bool`|`-`|Разрешено ли изменять значение параметра между группами|

---

**Примечания:**
- Если поле `severity` не указано, по умолчанию оно равно `Message`.
- Если поле `isActive` не указано, по умолчанию оно равно `true`.
- Если поле `isObsolete` не указано, по умолчанию оно равно `false`.
