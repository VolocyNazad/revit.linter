> Язык: [[Collision diagnostics|English]] · **Русский**

Список проверок и их поведение задаются в YAML-файле. Он должен находиться в [[Размещение файлов конфигурации|папке конфигурации]] соответствующей версии Revit. Файл должен называться `collision.config.yaml`.

Готовый файл: [collision.config.yaml](../../../examples/configuration/collision.config.yaml).

---

**Параметры:**

| Поле                  | Тип             | Тип входных данных | Тип возвращаемого значения формулы | Назначение                                                                                                                                               |
| --------------------- | --------------- | ------------------- | -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `code`                | строка          | `string`            | `-`                              | Уникальный идентификатор проверки                                                                                                                        |
| `description`         | строка          | `string`            | `-`                              | Описание проверки                                                                                                                                        |
| `message`             | строка          | `string`            | `-`                              | Шаблон сообщения об ошибке. Доступные переменные: `{elementName}`, `{elementId}`, `{intersection.elementNames}`, `{intersection.elementIds}`, `{intersection.count}`, `{duration}`. Находка перечисляет все элементы, с которыми пересекается целевой: `{intersection.elementNames}` и `{intersection.elementIds}` — списки через запятую в одинаковом порядке, `{intersection.count}` — их количество (по умолчанию: локализованный общий шаблон) (необязательно) |
| `severity`            | перечисление    | `string`            | `-`                              | [[Уровни важности]] (по умолчанию: `Message`) (необязательно)                                                                  |
| `isActive`            | логический | `bool`              | `-`                              | Активна ли проверка (по умолчанию: `true`) (необязательно)                                                                                              |
| `isObsolete`          | логический | `bool`              | `-`                              | [[Устаревшие проверки]] (по умолчанию: `false`) (необязательно)                                                                   |
| `obsoleteDescription` | строка          | `string`            | `-`                              | [[Устаревшие проверки]] (отображается, когда `isObsolete: true`) (необязательно)                                    |
| `takeDocument`        | строка          | `string`            | `bool`                           | [[Синтаксис формул\|Формула фильтрации документов]]                                                                                                 |
| `take`                | строка          | `string`            | `ElementFilter`                  | [[Объекты Revit в формулах\|Формула отбора первой группы элементов]] для проверки коллизий                                                                   |
| `andTake`             | строка          | `string`            | `ElementFilter`                  | [[Объекты Revit в формулах\|Формула отбора второй группы элементов]], с которой проверяются пересечения                                                      |
| `groupBy`             | строка          | `string`            | `object`                         | [[Объекты Revit в формулах\|Формула группировки элементов]]. Коллизии ищутся отдельно внутри каждой группы.                                                         |
| `includeLinks`          | логический | `bool`         | `-` | Участвуют ли загруженные Revit-связи в проверке только для чтения (по умолчанию: `false`) (необязательно) |
| `ignoreConnectedElements` | логический | `bool`         | `-` | Исключать ли элементы, соединённые коннекторами MEP, из проверки (по умолчанию: `false`) (необязательно) |

## Связанные модели и соединённые элементы

- Связи участвуют только если правило задаёт `includeLinks: true` (по умолчанию `false`), поэтому существующие конфигурации работают как раньше.
- Участвуют все загруженные связи; выбора отдельных связей нет. Поддерживаются только прямые связи, незагруженные пропускаются с предупреждением, а замечания остаются на элементах хоста: пары «связь против связи» никогда не проверяются.
- Попадания по связям остаются в отчёте только текстом: они не входят в список зависимостей, поэтому визуализации подсвечивают только целевой элемент хоста, а исправления действуют только на хост. Имена элементов связей выглядят как `Имя [Связь]` в `{intersection.elementNames}`.
- Связь с неконформной трансформацией проверяется только по ограничивающим параллелепипедам, без проверки тел.
- `ignoreConnectedElements: true` пропускает элементы, соединённые с целевым коннекторами MEP: они стыкуются по проекту, а их геометрия семейств пересекается в месте стыка. Пара, которая реально пересекается ещё где-то, тоже пропускается. Флаг действует только на пары внутри хост-документа: коннекторы не соединяют элементы через Revit-связи.

**Примечания:**
- Если поле `message` не указано, по умолчанию используется локализованный общий шаблон.
- Если поле `severity` не указано, по умолчанию оно равно `Message`.
- Если поле `isActive` не указано, по умолчанию оно равно `true`.
- Если поле `isObsolete` не указано, по умолчанию оно равно `false`.
- Если поле `includeLinks` не указано, по умолчанию оно равно `false`: связи участвуют только при явном включении, а попадания по ним остаются в отчёте только текстом.
- Если поле `ignoreConnectedElements` не указано, по умолчанию оно равно `false`. Установите `true`, чтобы пропускать соединённые элементы: они стыкуются по проекту, а их геометрия семейств пересекается в месте стыка и иначе считалась бы коллизией. Пара, которая реально пересекается ещё где-то, тоже пропускается. Флаг действует только на пары внутри хост-документа: коннекторы не соединяют элементы через Revit-связи.
