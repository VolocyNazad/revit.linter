> Язык: [[Built-in element diagnostics|English]] · **Русский**

| Код           | Описание                                                                                     | Уровень      | Пример сообщения                                                                     |
| :----------- | :---------------------------------------------------------------------------------------------- | :--------- | :---------------------------------------------------------------------------------- |
| **SHRD003**  | Проверяет, не отражены ли экземпляры семейств зеркально.                                           | ⚠️ Предупреждение | `Instance 'Окно_Стандарт' (ID:99887) is mirrored. (12 ms)`                          |
| **SHRD004**  | Проверяет, размещены ли виды на листах.                                                      | ⚠️ Предупреждение | `View 'Разрез А-А' (ID:55443) is not placed on a sheet. (9 ms)`                     |
| **SHRD005**  | Проверяет, прикреплена ли стена сверху.                                                 | ⚠️ Предупреждение | `Wall 'Стена_Внешняя' (ID:33221) has no top attachment. (7 ms)`                     |
| **SHRD006**  | Проверяет координаты размещения линейных элементов с учётом допуска.                                  | ⚠️ Предупреждение | `Element 'Ось 1' (ID:77665) has invalid coordinates. (14 ms)`                       |
| **SHRD007**  | Проверяет длину линейных элементов с учётом допуска.                                          | ⚠️ Предупреждение | `Element 'Балка_01' (ID:44332) has an invalid length. (11 ms)`                      |
| **SHRD008**  | Проверяет отметки уровней с учётом допуска.                                                       | ⚠️ Предупреждение | `Level 'Уровень 2' (ID:55667) has an invalid height. (5 ms)`                        |
| **SHRD009*** | Проверяет координаты размещения перекрытий с учётом допуска.                                               | ⚠️ Предупреждение | `Floor 'Плита_01' (ID:88990) has invalid coordinates. (13 ms)`                      |
| **SHRD0010** | Проверяет высоту размещения экземпляров семейств с учётом допуска.                                         | ⚠️ Предупреждение | `Instance 'Светильник_01' (ID:22334) has an invalid height. (10 ms)`                |
| **SHRD0011** | Проверяет, используются ли параметры в документе.                                                     | ⚠️ Предупреждение | `Parameter 'Заказчик_ДопПоле' (ID:44556) is not used. (8 ms)`                       |
| **ARCH004**  | Проверяет высоту стен с учётом допуска.                                                        | ⚠️ Предупреждение | `Wall 'Стена_Внутренняя' (ID:77889) has an invalid height. (8 ms)`                  |
| **ARCH001**  | Проверяет, размещено ли помещение.                                                                | ❌ Ошибка    | `Room 'Комната 101' (ID:11223) is not placed. (6 ms)`                               |
| **ARCH002**  | Проверяет, является ли помещение замкнутым.                                                              | ❌ Ошибка    | `Room 'Комната 102' (ID:33445) is not enclosed. (7 ms)`                             |
| **ARCH003**  | Проверяет, является ли помещение избыточным.                                                             | ❌ Ошибка    | `Room 'Комната 103' (ID:55667) is redundant. (5 ms)`                                |
| **SYST001**  | Проверяет трубы, воздуховоды, кабельные лотки, короба и экземпляры пользовательских семейств на наличие неподключённых соединителей. | 💬 Сообщение | `Element 'Труба-01' (ID:12345) has unconnected connectors. (15 ms)`                 |
| **SHRD001**  | Проверяет, используются ли семейства в документе.                                                      | 💬 Сообщение | `Family 'Вентилятор_Старый' (ID:67890) is not used. (8 ms)`                         |
| **SHRD002**  | Проверяет, используются ли типоразмеры семейств в документе.                                                  | 💬 Сообщение | `Type 'Дверь_1200x2400' (ID:11223) is not used. (6 ms)`                             |
| **SHRD0012** | Проверяет, связан ли экземпляр семейства с ближайшим уровнем.                          | 💬 Сообщение | `Instance 'Колонна_01' (ID:66778) is not associated with the nearest level. (9 ms)` |

> \* `SHRD009` доступен только в версиях Revit `AFTER2023`.
