# Quick start

The normal workflow is:

`Model → Diagnostics → Findings → Show or fix → Export report`

## A document is already open

1. On the **Diagnostics** ribbon tab, open [[Diagnostics pane|Diagnostics]] and [[Diagnostic reports pane|Diagnostic results]].
2. In **Diagnostics**, select the checks that fit the model. Start with [[Built-in diagnostics and user rules|built-in diagnostics]]; they need no configuration.
3. In **Diagnostic results**, select the active document and press **Run**.
4. Select a finding, read its message, and use **Show** to locate the affected element.
5. Apply a suggested fix only after reviewing the confirmation. Export the displayed findings when you need a shareable report.

## No document is open

Open [[Getting started button|Getting started]] and choose one of these paths:

- prepare a fresh copy of an official Autodesk sample found for the running Revit version; or
- start the practical tour and open your own project or family when ready.

The practical tour waits for a document and resumes automatically. See [[Practical tour]] for progress, opt-out, and reset behavior.

Revit normally docks the panels at the bottom of the window. You can move, resize, or float them like other [[Dockable panes|dockable panes]].

> **Note:** **Show** frames or otherwise visualizes the finding in the active Revit view. Clicking the same active visualization again restores the previous view state.
