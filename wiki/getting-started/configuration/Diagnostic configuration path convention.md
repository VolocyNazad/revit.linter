Configurations are stored separately for each Revit version:

See [[Diagnostic configuration path|configuration paths for supported Revit versions]].

Example for Revit 2021:

`C:\Users\Owner\Documents\Revit Linter\2021\`

Use the [[Diagnostic configuration path button|configuration folder button]] to open the correct directory from Revit.
