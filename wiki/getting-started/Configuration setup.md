> Language: **English** · [[Настройка конфигурации|Русский]]

Revit Linter stores YAML configuration separately for each installed Revit version.

1. Use the [[Diagnostic configuration path button|configuration folder button]] on the **Volocy** tab.
2. Open the folder for the Revit version you are currently running.
3. Start from one of the [[Configuration examples|configuration examples]].
4. Save the YAML file with the required module filename.
5. Return to Revit and run diagnostics again.

See [[Diagnostic configuration path convention|configuration folder conventions]] for the exact location and [[Documentation|Documentation]] for available diagnostic modules.
