> Language: **English** · [[Настройка конфигурации|Русский]]

Revit Linter stores one `diagnostics.config.yaml` per installed Revit version.

1. Use the [[Diagnostic configuration path button|configuration folder button]] on the Diagnostics pane.
2. Open the folder for the Revit version you are currently running.
3. Start from the [[Configuration examples|example configuration]].
4. Save the file as `diagnostics.config.yaml`; every rule keeps its `type`.
5. Return to Revit and run diagnostics again.

See [[Diagnostic configuration path convention|configuration folder conventions]] for the exact location, [[Configuration file|Configuration file]] for the format and [[Migrating configuration|Migrating configuration]] when you still have the old split files.
